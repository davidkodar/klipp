# Appearance Preferences

Access appearance preferences from **Edit > Preferences > Appearance**.

## UI Scale

Adjust the overall interface scaling factor:

- **Auto** -- Match system DPI settings (default)
- **100%** -- Standard size
- **125%** -- Slightly larger, good for high-DPI displays
- **150%** -- Large, suitable for 4K monitors at native resolution
- **175%** -- Extra large
- **200%** -- Double size

UI scale affects all panels, text, buttons, and controls uniformly. Changes take effect immediately.

## Accent Color

Klipp uses amber as its accent color throughout the interface for selected items, active controls, and highlighted elements. The accent color can be customized:

- **Amber** -- Default Klipp accent
- **Blue** -- Traditional editing application feel
- **Green** -- Alternative accent
- **Custom** -- Pick any color with the color picker

The accent color is used for:
- Selected items in the browser and timeline
- Active tool indicators
- Playhead color
- Button highlights and focus rings

## Role Colors

Timeline clips can be assigned role colors for visual organization:

- **Video** -- Default color for video clips
- **Audio** -- Default color for audio clips
- **Titles** -- Color for title/generator clips
- **Effects** -- Color for adjustment layers and effects

Each role color appears as a tint bar along the top edge of clips on the timeline.

## Theme

Klipp uses a dark interface theme optimized for color-critical work. The dark background reduces eye strain during long editing sessions and minimizes interference with color perception when grading.

Amber and gold background elements always use dark text for readability, following Klipp's contrast guidelines.

## Font Size

Adjust the base font size independently of UI scale:

- **Small** -- Compact text, fits more information
- **Medium** -- Default size
- **Large** -- Easier to read, uses more space
