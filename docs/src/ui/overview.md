# User Interface Overview

Klipp's interface follows a standard NLE layout with customizable panels and workspace presets.

## Default Layout

The default workspace arranges four main areas:

```
+---------------------------+------------------+
|                           |                  |
|         Viewer            |  Media Browser   |
|                           |                  |
+---------------------------+------------------+
|                                    | Inspector|
|             Timeline               |          |
|                                    |          |
+------------------------------------+----------+
```

- **Menu Bar** -- Runs across the top of the window with all menus and the toolbar.
- **Viewer** -- Top-left. Displays the current frame at the playhead position with transport controls.
- **Media Browser** -- Top-right. Shows imported media with grid/list views, bins, and skimming.
- **Timeline** -- Bottom area. Multi-track timeline with video and audio tracks, filmstrip thumbnails, and waveforms.
- **Inspector** -- Right side. Context-sensitive panel showing video, audio, color, and info tabs for the selected clip.

## Workspaces

Klipp provides three workspace presets accessible from **Window > Workspaces**:

- **Default** -- Balanced layout for general editing with all panels visible.
- **Color Grading** -- Expanded viewer and color panel with scopes visible, timeline compressed.
- **Audio Mixing** -- Audio tracks prominent with expanded meters, EQ, and volume controls.

## Panel Visibility

Toggle individual panels from the **Window** menu:

- Viewer
- Media Browser
- Timeline
- Inspector
- Color Panel
- Scopes
- Audio Meters

## Navigation

- Click on any panel to give it focus.
- The **Command Palette** (**Ctrl+Shift+P**) provides quick access to any command.
- The status bar at the bottom of the timeline shows clip count, selected clip info, filmstrip statistics, and zoom level.

## Themes

Klipp uses a dark theme with amber accent colors. UI scale and accent colors can be adjusted in **Edit > Preferences > Appearance**.
