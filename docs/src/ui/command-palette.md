# Command Palette

The command palette is a search overlay over Klipp's commands. Open it with **Ctrl+K** and start typing: the list narrows to the entries whose name or shortcut contains what you typed, in the order they are listed.

It is the fastest way to:

- Run a command whose menu location you can't remember
- Avoid mouse travel in keyboard-heavy sessions
- Discover commands you didn't know existed — with the search box empty, the whole list is browsable with the arrow keys

## Coverage

The palette lists the project and file commands, the edits, the panels and overlays to show or hide, the scope options, the AI tools, the audio clean-ups and the maintenance tools. Some examples:

- `New Project`, `Open Project from Another Editor…`, `Colour Management…`, `Export…`
- `Insert Edit`, `Overwrite Edit`, `Split at Playhead`, `Swap Selected Clips`
- `Fade From Black (1 s)`, `Bake Grade as 3D LUT (.cube)`
- `Find in Timeline`, `Find and Replace in Titles…`, `Captions from Transcript…`
- `AI: Remove Background`, `AI: Track Object`, `Manage AI Models…`
- `Hum Removal — 50 Hz (Europe/Asia)`, `Camera Wind — rumble reduction`
- `Toggle Performance Overlay`, `Toggle Delivery Check`, `Project Doctor…`

## Search

The search is case-insensitive and matches anywhere in the name or the shortcut: `back` finds `AI: Remove Background`, and `ctrl+e` finds `Export…`.

## Keyboard

| Key | Action |
|---|---|
| **Ctrl+K** | Open / close palette |
| **↑ / ↓** | Move selection |
| **Enter** | Run selected command |
| **Esc** | Close without running |
