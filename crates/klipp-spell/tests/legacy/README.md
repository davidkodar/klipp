# Hunspell's test cases

These files are Hunspell's dictionary test cases, as spellbook carries
them: copied unchanged from spellbook 0.4.2's `tests/legacy/` (the
crates.io release, https://crates.io/crates/spellbook/0.4.2), which ports
them from the Hunspell codebase (https://github.com/hunspell/hunspell,
`tests/`) by way of Nuspell's test bed. Spellbook does not name the Hunspell
version they were taken at.
